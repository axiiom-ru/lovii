# LOVII — публичные документы

Официальный источник актуальных версий публичных документов платформы **LOVII**.

Каждый документ доступен:

- **в этом репозитории** — исходная Markdown-версия (единый источник правды);
- **через GitHub Pages** — по стабильной ссылке для публикации на внешних сайтах.

> Ссылки ниже всегда ведут на актуальную версию — править нужно только файлы в папке [`docs/`](docs/).

## Как добавить документ

1. Положите файл в папку [`docs/`](docs/).
2. Добавьте строку в таблицу выше.
3. Закоммитьте и запушьте в `main` — GitHub Pages обновит ссылки автоматически.
