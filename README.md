# LOVII — цифровая платформа локальной экономики

**LOVII** — SaaS-платформа для микро-, малого и среднего предпринимательства (МСП): объединяет локальный бизнес — пекарни, кофейни, магазины, химчистки, салоны, рынки и службы доставки — в единой цифровой инфраструктуре с общей программой лояльности.

> **Простыми словами:** «Лови» — приложение, где собраны все местные кафе, пекарни, магазины и сервисы твоего района. Это единая карта лояльности на весь район: баллы, кэшбэк и витрина локального бизнеса в одном месте.

---

## Основная цель

Построить **комплексную информационную платформу локальной экономики (КИП)** — цифровую витрину и экосистему лояльности, которая:

- даёт **микробизнесу** готовую цифровую инфраструктуру и короткий путь к собственному клиенту;
- даёт **клиентам** единую программу лояльности на все местные точки района (баллы, кэшбэк, кросс-обмен);
- **агрегирует локальные сервисы** вместо конкуренции с федеральными агрегаторами (Яндекс, Ozon);
- масштабируется по городам через **франчайзинговую модель** (City Franchise): каждый город — отдельный экземпляр экосистемы со своим каталогом, аудиторией и командой (white-label, гео-изоляция).

## Суть модели

- **Агентская (лицензионная) модель:** платформа не владеет товарами, не перепродаёт и не хранит деньги клиентов.
- **Все расчёты проходят через банковского партнёра** (Т-Банк, Мультирасчёты) в рамках 161-ФЗ — автоматическое распределение платежей между участниками.
- **Доход платформы** — лицензионное вознаграждение и абонентская плата, а не маржа с товаров.

## Что включает платформа

**ПО для МСП** объединяет 12 функциональных доменов:

| № | Домен | Что входит |
|:--|:--|:--|
| 1 | **Общая архитектура** | Ролевая модель (клиент / торговая точка / курьер / представитель / амбасадор), безопасность, темизация |
| 2 | **Клиентская часть** | Витрина, каталог, заказ, программа лояльности, баллы, вывод через СБП, чаевые |
| 3 | **Бизнес-часть / ТСП** | Каталог товаров, приём и обработка заказов, касса, персонал, доставка |
| 4 | **Франчайзи** | Управление точками, пункты выдачи (ПВЗ), рекламный доход локации |
| 5 | **Оператор** | Тарифы, роялти, мониторинг, интеграции, управление экосистемой |
| 6 | **Логистика** | Доставка (Igoods, Яндекс.Go, Чибис), курьерские заказы, статусы |
| 7 | **Реклама** | Баннеры, таргетинг, распределение рекламного дохода между участниками |
| 8 | **Кросс-лояльность** | Конвертер баллов между точками, обмен баллов, офлайн-оплата через QR |
| 9 | **Финансы и юр. инфраструктура** | Консолидатор платежей, самозанятые (НПД), банковский партнёр (БПА / Мультирасчёты) |
| 10 | **HR и обучение** | Портал, обучение, бонусы, рейтинги, корпоративная мотивация |
| 11 | **API** | REST / GraphQL, вебхуки, white-label виджет для сторонних сайтов |
| 12 | **Дополнительно** | Локализация, поддержка, модерация, AI-рекомендации |

### Роли в экосистеме

- **Клиент** — покупает в маркетплейсе, получает баллы лояльности
- **Торговая точка (Лицензиат)** — бизнес на платформе, работает с заказами
- **Курьер** — доставка по приглашению оператора
- **Цифровой представитель / Мэр / Губернатор** — партнёрская сеть развития городов
- **Амбасадор** — обучение и мотивация партнёрской сети

### Тарифы для торговых точек

| Тариф | Абонплата | Комиссия с заказа |
|:--|:--|:--|
| **Лови Старт** | 0 ₽/мес | 5–10% |
| **Лови Про** | 2 990 ₽/мес | 4–7% |
| **Лови Бизнес** | Индивидуально | Для сетей |

### Технологический стек

- **Frontend:** React + Vite + Tailwind CSS; React Native + Expo (мобильные)
- **Backend:** микросервисы + event-driven (Kafka, CQRS, Saga), core-сервисы на Go
- **Данные:** PostgreSQL (кластер 2N+1), Redis, ClickHouse
- **MVP:** PWA (прогрессивное веб-приложение)

### Соответствие требованиям

152-ФЗ (персональные данные), 161-ФЗ (платёжные системы), 54-ФЗ (кассы), 115-ФЗ (антиотмывочный), PCI DSS, KYC/AML — хранение данных в РФ.
